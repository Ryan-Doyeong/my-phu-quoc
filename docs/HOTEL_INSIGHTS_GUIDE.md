# 선셋타운 호텔별 '한눈에 보는 장단점' 데이터 작성 가이드

본 문서는 `data/hotel_insights.json` 파일의 작성 및 수정 가이드입니다.  
우리 웹사이트(myphuquoc.net)는 **'아고다에서 걸러내기 힘든 선셋타운 호텔을 1차로 추려 주고, 아고다 가기 전 핵심 요약과 장단점을 보여 주는 곳'**을 목표로 합니다. 상세 스펙은 아고다에서 직접 확인하므로, 불필요한 군더더기 없이 **핵심 포인트(위치 · 전망 · 컨디션 · 직원 수준 · 장단점)**를 구체적 사실에 근거하여 작성합니다.

---

## 1. 데이터 파일 위치
- **개발 레포**: `data/hotel_insights.json`
- **구글 드라이브 (PhuQuoc 폴더)**: `PhuQuoc/hotel_insights.json`

---

## 2. JSON 항목별 작성 표준

각 호텔은 고유 `slug`를 키로 가지며 아래 6개 필드로 구성됩니다:

```json
{
  "hotel-slug": {
    "location": "위치 핵심 (케이블카 거리, 주요 편의시설 도보 시간)",
    "view": "전망 사실 (오션뷰, 불꽃놀이 조망 여부, 시티뷰 등)",
    "condition": "컨디션 (침구 상태, 룸 청결도, 신축 여부, 소음/수압 등)",
    "staff": "직원 수준 (응대 태도, 사전 소통, 언어 소통, 서비스 친절도)",
    "pros": [
      "실제 투숙객이 체감할 수 있는 핵심 장점 1",
      "핵심 장점 2"
    ],
    "cons": [
      "예약 전 반드시 알아야 할 참고사항 및 아쉬운 점 1"
    ]
  }
}
```

### 필수 준수 규칙:
1. **미확인 항목 공백 유지 (자동 숨김)**:
   - 아직 직접 확인되지 않은 항목은 빈 문자열(`""`) 또는 빈 배열(`[]`)로 남겨두십시오.
   - 웹사이트에서 값이 없는 항목은 **자동으로 숨김 처리**되며, **'준비 중' 같은 문구는 절대 노출되지 않습니다.**
2. **구체적 수치와 사실 중심 기술**:
   - `최고`, `최단`, `초역세권`, `감성`, `만족도 100%` 등 근거 없는 최상급·과장 수식어는 금지합니다.
   - 예: `케이블카 도보 1분`, `오션뷰 객실에서 야간 불꽃놀이 관람 가능`, `포근한 매트리스 침구류 구비`.
3. **단점(cons) 작성 원칙**:
   - 무조건적인 비방이 아닌, 여행자가 예약할 때 혼선을 겪지 않도록 돕는 솔직하고 유용한 팁을 적습니다.
   - 예: `한 층에 객실 3개 중 오션뷰는 1개이므로 예약 시 룸 타입 확인 필수`, `엘리베이터가 없어 고층 배정 시 계단 이용 필요`.

## 3. 대표 작성 예시 (더 룸 호텔)

```json
{
  "the-room-hotel": {
    "location": "혼똔섬 케이블카 610m, 야시장·스타벅스·한식당 도보 1~3분",
    "view": "오션뷰 객실 발코니에서 야간 불꽃놀이 관람 가능 (시티뷰 객실 병행)",
    "condition": "포근한 침구류 구비 및 청결한 객실 관리",
    "staff": "체크인 전 사전 소통 및 친절한 직원·사장님 응대",
    "pros": [
      "오션뷰 객실 발코니에서 매일 밤 불꽃놀이 편안하게 관람",
      "포근하고 편안한 침구류로 안락한 휴식",
      "야시장, 스타벅스, 식당, 마트 도보 1~3분 인접",
      "친절하고 세심한 사장님과 직원의 맞춤 응대"
    ],
    "cons": [
      "한 층에 객실 3개 중 오션뷰 객실은 1개(예약 시 객실 유형 확인 필요)"
    ]
  }
}
```
