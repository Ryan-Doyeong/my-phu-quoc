# 아르곤 글로벌 후기 리포트 검증 + 마이 푸꾸옥 수익 전략 (2026-11-01)

결론: 아르곤 리포트의 큰 그림(시장 규모·채널·일정 선호)은 공식 통계와 맞지만, 세부 수치 일부는 과장이거나 출처가 없다. 마이 푸꾸옥은 **티켓 판매 수익이 없으므로** 티켓은 Klook 제휴 링크로 넘기고, 수익은 **환전·공항 왕복 차량·차량 투어·요트/호핑·현지 가이드** 5가지에 집중한다. 일정 생성기는 이 5가지가 "필요한 순간"에 자연스럽게 나오도록 바꾼다.

## 4. 국가별 마케팅 — 구체적 실행안

유입 채널은 아르곤 리포트 판단을 따르되, **우리가 직접 글을 올릴 수 있는 곳**과 **제휴가 필요한 곳**을 구분했다. 숫자 목표는 운영하며 정한다.

### 4.1 한국 (가장 큰 시장, 네이버 중심)
- 네이버 블로그·카페는 자동화 접근이 막혀 있다 → **사람이 직접 올려야 한다.** 주 2회, 일정 생성기 결과 화면 캡처 + "새벽 도착 체크인 전 4시간 쓰는 법" 같은 실용 글.
- 글 끝에 항상 WhatsApp/카카오톡 상담 → 픽업·차량 투어로 연결.
- 키워드: 푸꾸옥 새벽 도착, 푸꾸옥 공항 픽업, 푸꾸옥 남부 일정, 키스 오브 더 씨 무료 티켓.

### 4.2 러시아·CIS (장기 체류, Telegram)
- 수익 포인트가 가장 크다: 10~14박 체류 + 패키지 밖 개별 투어 수요. **러시아어 차량 투어·요트 투어 페이지**를 먼저 만든다.
- Telegram 오픈채팅은 **광고 글이 아니라 답변으로** 들어간다. 러시아어 가능한 담당자(또는 번역기)가 "공항→남부 요금", "프라이빗 보트" 질문에 답하며 사이트 링크. 채널명·규칙은 직접 확인 필요(미확인).
- 환전: 루블→동 P2P 환전 수요가 크다 → Viet Travel이 루블 취급 가능한지 확인 후 "공항 픽업 + 환전" 묶음.
- Yandex에 사이트 등록(Yandex Webmaster) — 러시아어 페이지 색인.

### 4.3 인도 (급성장, 웨딩·허니문)
- Instagram Reels가 트리거 → 선셋타운·키스브릿지·요트 드론 영상 (제작은 안티). 영어 자막.
- 허니문 = **프라이빗 요트 투어**가 핵심 상품. "Sunset yacht for two" 랜딩 페이지.
- 채식(Pure Veg/Jain) 식당 목록 페이지 — 돈은 안 되지만 유입·신뢰 요소. Maharaja Lounge 등 확인 후 등록.
- 아마다바드 직항 2026-12-02 취항 → 11월 중 구자라트 대상 영어 콘텐츠 준비.
- MakeMyTrip·Thrillophilia 입점은 업체 등록 요건 확인 필요(미확인).

### 4.4 대만·홍콩 (직항 무비자, 중국어 단독차량)
- 대만은 **包車(단독 차량 대절)** 문화 → 우리 차량 투어와 정확히 맞는다. 중국어(번체) 차량 투어 페이지 + LINE 연락 버튼(현재 WhatsApp·Zalo만 있음 — LINE 추가 검토).
- 홍콩은 Klook 본진 → 티켓은 Klook, 차량·요트는 우리. 샤오홍슈 포스팅은 계정 개설 필요(미확인).
- 사이트 /tw(번체) 페이지가 이미 있으니 차량 투어·요트 페이지부터 번체 번역.

### 4.5 일본 (조용한 휴양, 4travel)
- 소음 민감 → 선셋타운 공연 과다 노출보다 **옹랑·켐비치 휴식 + 프라이빗 요트** 소구.
- 4travel·note는 직접 글쓰기 가능. 일본어 검수는 ChatGPT.
- 공항 송영 포함 프리플랜 선호 → "픽업+샌딩 왕복" 묶음 상품.

### 4.6 공통
- 모든 나라 공통 최다 불만 = **공연 후 택시난** → "공연 후 귀가 차량 예약" 상품이 가장 설명이 쉬운 수익 상품. 공연 카드 바로 아래에 배치.
- 리포트 수치를 마케팅 문구에 쓰지 않는다(과장 위험). "2025년 외국인 180만 명" 같은 공식 수치만 사용.

## 5. 결정 필요
1. 현지 가이드: 가이드 풀(언어·요금)을 확보할 수 있는지 — 없으면 상품을 숨김 상태로 둔다.
2. LINE 연락 버튼 추가 여부 (대만·일본용).
3. Viet Travel 환전이 루블·루피를 취급하는지.
4. 프라이빗 요트 업체 확정 — 가격 공란 채우기.
