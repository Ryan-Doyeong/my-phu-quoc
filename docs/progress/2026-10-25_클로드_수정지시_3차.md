# Claude 수정 지시 3차 (2026-10-25)
규칙: 기존 파일 삭제·덮어쓰기 금지(새 파일/_v4). Supabase 반영은 계속 대기. 비밀번호·로그인 직접 입력 금지(로그인 화면이 나오면 멈추고 보고). 확인 안 된 것은 "미확인". 새 사물을 그려 넣거나 사진을 합성·변형 금지(자르기·크기 조정만 허용).

## A. 대표(타이틀) 이미지 규칙 (Ryan 결정)
1순위: 해당 업체의 공식 홈페이지(website_url) 또는 공식 SNS(instagram_url 등)에 이미 올라와 있는 실제 사진이 있으면 그 사진을 타이틀 사진으로 사용.
2순위: 위 사진이 없으면 지금처럼 단색 배경 + 영어 상호 레터링(BusinessCover).
- 사진을 쓰는 업체마다 출처 URL을 data/cover-photos.json(새 파일)에 {slug, image_url, source_page_url, found_at} 로 기록. 상세 화면 사진 아래 작은 글씨로 "사진 출처: 업체 공식 홈페이지/SNS" 링크 표시.
- 우선 선셋타운 291곳(특히 식당·호텔·카페 등 방문 많은 곳)부터. 업체 수가 많으므로 자동 수집 스크립트(scripts/collect_cover_photos.mjs)로 처리하고, 한 업체당 확인에 오래 걸리면 건너뛰어 2순위로.
- 수집한 사진은 가능하면 원본 URL을 참조(핫링크)하되, 불안정하면 public/covers-photo/ 아래 새 폴더에 저장. 저작권 문제로 보이는 경우(스톡·타 업체 사진, 워터마크, 사람 얼굴이 크게 나온 사진)는 쓰지 말고 2순위로.
- 구글 지도 사진·OSM·스톡 사진은 사용 금지.
- 로그인이 필요한 SNS(인스타그램 등)는 로그인하지 말고, 공개로 보이는 것만 사용. 못 보면 2순위.

## B. 이전 지적 사항 수정
1. 분류 표시: 상단 분류에 international 같은 영어 원문 값이 그대로 나온다. 한국어 화면에서는 한글(예: 국제 요리/광동식 중식 등)로 표시하도록 subcategory 표시 사전(7개 언어)을 만들 것. 번역 품질 검수는 하지 말고, 번역이 필요한 문구 목록만 별도 파일로.
2. 레터링 이미지: 글자 크기를 키우고(박스 폭의 약 60~70%), 2줄까지 줄바꿈, 대비 확보. 카테고리별 배경색은 브랜드 팔레트 안에서 유지.
3. 호텔 상세·모바일 스크린샷이 로딩 중 빈 화면으로 찍혔다. 페이지 로딩 완료 후 다시 촬영해 _v4로 저장.
