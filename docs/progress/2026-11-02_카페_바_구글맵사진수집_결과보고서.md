## 5. 핵심 준수 규칙 및 기술적 안전 조치 이행 확인

1. **무합성 원칙 100% 준수**: 구글맵 이용자 실측 사진 기반의 밝기/대비/수평 보정만 적용, 사물/인물 인위적 추가 합성 절대 없음.
2. **인물 얼굴 클로즈업 완전 배제**: Apple Vision 안면 검출기 전수 스캔 결과, 인물 얼굴이 크게 나온 사진 0건 달성 (음식, 매장 인테리어, 외부 전경 우선).
3. **출처 표기 통일**: 모든 수집 사진은 상세 페이지 갤러리 하단에 `사진 출처: Google Maps ↗` 및 삭제·수정 요청 링크 연동 완료 (`media_note: 'Google Maps'`, `photo_permission: 'google_maps_verified'`).
4. **상호명 표준 준수**: 구글맵 공식 명칭 기준 한글/영문 병기 표준화, 한자/다국어/프로모션 태그 배제 완료, 기존 명칭 alias 보존, `slug` 및 URL 100% 불변 유지.
5. **비공개 13곳 엄격 유지**: 임의 공개 전환이나 데이터 삭제 없이 기존 비공개 상태 유지.
6. **안전 수칙**: `main` 브랜치 직접 푸시/머지 금지, Supabase SQL 프로덕션 실행 금지 준수. 모든 작업은 `feat/venue-photos-google-maps-20261102` 내 PR #16 (Draft)에서 유지.
