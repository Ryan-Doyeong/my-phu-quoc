## 1단계: 데이터 정리
1) description_en에서 한국어 제거(영어만). 선셋타운 291건 verification_status 'verified' → 'ai_checked'(메모: "Master DB 수집 2026-10, 현장 미확인"). 푸꾸옥 전역 262건은 status 'review'(비공개).
2) 카페가 bars로 들어간 건 dining/cafe로, subcategory 'yes' 등 OSM 원시값 정리. 설명 속 원화 환산 요금 삭제(VND만, "2026-10 기준" 표기).
3) businesses.google_place_id 추가 + 값 채우기(google_maps_url의 place_id 추출). 메뉴 테이블 business_menu_items(업체FK, 섹션, 원문명, 한글명, 영문명, 가격VND, 등급A~D, 출처, 확인일) 설계. 마이그레이션 번호는 기존 022_site_media_storage.sql 다음인 023_place_id_and_menus.sql. supabase/seed_phuquoc_businesses_v2.sql, seed_menus.sql(menus/*.json 59곳 연결) 생성. 파일까지만, DB 반영 금지.

## 2단계: 사이트 화면 구축(선셋타운 우선, 로컬 npm run dev로 확인)
1) 홈: 히어로 카피를 선셋타운 특화(키스브릿지, 불꽃놀이, 야경). 구역 필터(소렌토·아말피·베니스·힐사이드 등).
2) 디렉토리: 선셋타운 291곳 우선, 카테고리·구역·가격대 필터, 지도 링크.
3) 업체 상세: 기본정보, 영업시간, 메뉴(등급 A~D 뱃지 + "가격은 현장과 다를 수 있음" 안내), 구글맵 링크.
4) 메뉴 섹션: A등급 전체 메뉴, B~D등급은 확인된 범위만, 나머지는 "미확인".
5) 뉴스·이벤트 게시판은 기존 구조 유지. 확인 안 된 이벤트 정보는 넣지 말 것.
6) 7개 언어 라우팅·메타태그·sitemap·robots 점검. 번역 품질 검수는 하지 말고 번역 필요 문구 목록만 작성(언어 검수는 ChatGPT 담당).
7) 모바일 우선, 성능·SEO 기본 점검.
