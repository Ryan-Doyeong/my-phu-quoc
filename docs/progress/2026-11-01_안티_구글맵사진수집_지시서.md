# [안티 지시서 2차] 구글맵 업체 사진 수집·보정 + 비활성 업체 선별 (2026-11-01, Claude 총괄)

사용자(Ryan) 결정 (2026-11-01): 베트남은 구글 API 발급이 불가 → **안티가 구글맵 화면에서 업체 사진을 캡처해 보정한 뒤 사이트에 사용**. 사이트는 현재 파일럿(비활성) 상태라 진행 가능. **구글맵 등록 사진이 3장 이하인 업체는 영업 활성 상태로 보기 어렵다고 판단 → 비공개 후보.**

## 대상
- `data/businesses-registry.json` 의 `status='published'` 업체 중 **gallery_urls 가 비어 있거나 대표 사진이 폐기(revoked)된 업체** (약 215곳).
- **제외**: category `hotels`(호텔 페이지가 별도 운영), `banking`(ATM·은행 — 사진 불필요, 비활성 판정 대상 아님). 이 업체는 카테고리 기본 이미지 사용.

## 업체 1곳당 절차 (Chrome에서)
1. 구글맵 열기: `https://www.google.com/maps/search/?api=1&query=<google_maps_name 또는 public_name>&query_place_id=<google_place_id>` → 해당 업체 장소 패널 확인(좌표 lat/lng 와 일치).
2. **사진 수 확인**: 패널의 "사진" 탭/"Photos" 개수(또는 갤러리 스크롤로 세어 3장 초과 여부)를 기록. → `구글맵 사진 수` 열에 숫자(또는 "3 이하")로 기록.
3. **사진이 3장 이하**: 사진 수집하지 말고 "비활성 후보" 목록에 slug·업체명·사진 수·최근 리뷰 날짜(보이면)·영업상태 표시를 기록. **status 는 바꾸지 말고 Claude에게 목록 보고**(승인 후 일괄 비공개).
4. **사진이 4장 이상**: 업체를 대표하는 사진 **1~3장**을 고른다.
   - 선택 기준: 외관·내부·음식·시술/시설 등 **업체 실제 모습**, 가로형, 밝고 선명.
   - 제외: 메뉴판·가격표·영수증, 홍보 배너/포스터, 로고, 광고 문구가 크게 박힌 이미지, 지도/스크린샷 UI, 타 지점·타 도시 사진, 얼굴이 크게 나온 인물 클로즈업(고객·직원 초상), 어두워 식별 불가한 사진.
5. **캡처**: 사진을 크게 연 상태에서 사진 영역만 캡처. 구글 UI·워터마크·사용자 이름 표시가 사진에 들어가지 않게 잘라낸다. 원본 해상도가 **가로 900px 미만**이면 버리고 다른 사진 선택.
6. **보정(재 보정)**: 가로 16:10 크롭, 노출·대비·채도 소폭 보정, 수평 보정, 잡티 정리 정도만. **원본에 없는 사물·인물·장식·문자를 절대 추가하지 말 것**(나비·새·장식 등 금지). 과도한 AI 생성·합성 금지.
7. 저장: `public/covers-photo/<slug>-g1.webp` (g2, g3), WebP, **가로 1400px 이하, 파일당 300KB 이하**(`node scripts/shrink-cover-photos.mjs` 사용 가능).
8. 기록:
   - `data/businesses-registry.json` 해당 업체: `gallery_urls`에 경로 추가, `media_note`: `Photo: Google Maps (contributor photo), captured 2026-11-01 — request removal via site form`, `photo_permission`: `Google Maps public listing photo (unverified rights)`.
   - `data/cover-photos.json`: 항목 추가(`slug`, `image_url`, `original_image_url`=구글맵 장소 URL, `source_page_url`=구글맵 장소 URL, `found_at`, `status`='active').
