# Claude 긴급 수정 지시 — 홈페이지 지도 상단 점령 문제 (2026-10-26, Ryan 지시)

## 증상 (Claude가 https://myphuquoc.net/ko 에서 직접 확인)
- 선셋타운 일러스트 지도가 홈 최상단에 화면 전체로 올라와 헤더·히어로를 덮음. 홈이 정상 화면이 아님.

## 원인 (Claude 진단, 코드 확인 완료)
- components/SunsetTownMap.tsx 가 Tailwind 유틸리티 클래스(relative, absolute, fill 부모 aspect-[4/3], grid, lg:col-span-6, bg-gradient-* 등)로 작성되어 있는데, 이 프로젝트에는 Tailwind가 없음(package.json·postcss.config·tailwind.config 모두 없음, globals.css에 유틸리티 정의 0건).
- 그래서 `relative`가 적용되지 않아 `<Image fill>`(position:absolute)이 페이지 맨 위 전체를 덮고, 라이트박스·그리드 레이아웃도 깨짐.

## 수정 (Tailwind 설치 금지 — 기존 CSS 방식으로)
1. SunsetTownMap.tsx(와 SunsetTownMapClient.tsx)의 모든 Tailwind 클래스를 제거하고 app/globals.css(또는 CSS 모듈)의 일반 CSS 클래스로 재작성.
   - 지도 사진 박스: position:relative; width:100%; max-width:560px; aspect-ratio:4/3; overflow:hidden; border-radius:16px.
   - next/image fill 은 반드시 위 relative 부모 안에서만 사용.
   - 라이트박스(확대): position:fixed; inset:0; z-index는 헤더보다 높게; 닫기 버튼·ESC·바깥 클릭 닫기. 평소엔 렌더링하지 않음.
   - 12개 명소 카드 목록: 2열(데스크톱)/1열(모바일) 그리드, 모바일 390px 가로 스크롤 없음.
2. 지도는 홈의 #map 섹션(스토리/티켓 근처, 지금 HomePage.tsx 378행 위치)에만 표시. 홈 최상단은 이전처럼 헤더 → 히어로(키스브릿지 항공 사진) 순서.
3. Ryan의 직전 요청도 함께 반영: 메인 타이틀(히어로) 화면은 선셋타운 전망 사진(확정: 02_kiss_bridge_aerial WebP), 각 카테고리 대표 사진은 AI 생성했던 그 사진 사용. 모든 이미지는 WebP.
4. 다른 컴포넌트(SunsetTownTickets, SunsetDistrictFilter 등)에도 Tailwind 클래스가 있는지 grep 해서 같은 문제면 같이 수정.
