## 3. 가격 배지 확장 구현 상세

### 3.1 공통 배지 컴포넌트 (`components/HotelPriceBadge.tsx`)
```tsx
export function HotelPriceBadge({
  priceRange,
  className = 'cardPriceBadge',
  style,
  checkDate = '2026-11-01',
}: HotelPriceBadgeProps) {
  if (!priceRange) return null
  const level = getPriceTierLevel(priceRange) || priceRange.length
  return (
    <span
      className={className}
      style={style}
      title={`아고다 기준 1박 요금대 (5단계 중 ${level}단계), 조회일: ${checkDate}`}
    >
      {priceRange}
    </span>
  )
}
```

### 3.3 단일 조회 헬퍼 (`lib/hotels.ts`)
- `getHotelPriceRangeForBusiness(b)`:
  - 1순위: 슬러그 일치 여부
  - 2순위: Google Place ID 일치 여부

  - 미확인/미등록 호텔은 `undefined` 반환하여 화면에서 자동 숨김 처리.
