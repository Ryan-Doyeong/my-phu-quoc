# [안티 지시서] 마이푸꾸옥 업체 구글맵 검증 + 대표 사진 수집 (2026-10-31, Claude 총괄)

## 목표
공개(published) 업체 278곳 전부에 대해 ① 구글맵 실재 여부 검증 ② 대표 사진 1~3장 확보 ③ 확인 불가 업체는 **비공개(status='hidden' 또는 기존 비공개 상태값) 처리 — 삭제 금지**.

## 작업 순서 (업체 1곳 단위로 반복)
1. Supabase `businesses` 에서 `status='published'` 목록 추출 (slug, public_name, google_maps_name, address, google_place_id, lat, lng, website_url, facebook_url, instagram_url). lat/lng 가 있는 85곳은 이미 검증됨 → 2번만 수행.
2. Mac 크롬에서 구글맵 열기: `https://www.google.com/maps/search/?api=1&query=<상호명 Sunset Town Phu Quoc>&query_place_id=<google_place_id>`
   - 해당 상호가 선셋타운/켐비치 안에 실제로 뜨면 → 구글맵 상세의 실제 place_id·좌표(URL의 @lat,lng)·영문 상호를 기록하고 DB `google_place_id`, `lat`, `lng`, `google_maps_name` 갱신.
   - 검색 결과가 없거나 다른 지역 업체만 나오면 → 해당 업체 `status`를 비공개로 변경하고 "미확인 목록"에 기록. (삭제 금지)
3. 사진 수집 (검증된 업체만): 우선순위 ① 업체 공식 홈페이지 ② 공식 Facebook/Instagram ③ 선셋타운 공식 채널(Sun Paradise Land). **구글맵에 올라온 사진은 저장·재게시 금지**(구글 약관) — 구글맵은 확인 용도만.
   - 1~3장, 가로형 우선, 최소 1200px, 모두 WebP 변환(사이트 규칙), 파일명 `public/covers-photo/<slug>-1.webp` 형식.
   - 출처 URL을 `media_note` 또는 `photo_permission` 필드에 기록, 화면에 "Photo: <출처>" 표기되도록 `gallery_urls` 배열에 경로 저장.
   - 공식 사진이 전혀 없는 업체는 사진 없이 두고 "사진 없음 목록"에 기록 (비공개 여부는 Claude/Ryan 결정).
4. 10곳 단위로 진행 상황을 `docs/progress/2026-10-31_안티_업체검증_결과.md` 에 추가 기록 (slug, 결과: 검증/비공개/사진N장/출처).
