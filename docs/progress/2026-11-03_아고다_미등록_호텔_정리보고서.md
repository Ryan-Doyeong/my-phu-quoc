## 2. 결함 수정 및 컴포넌트 방어 코드 강화

1. **`formatReviewLabel` 널 방어 (`components/HotelsPage.tsx`)**:
   - `count == null || isNaN(count)`인 경우 즉시 빈 문자열(`''`) 반환하여 `TypeError: Cannot read properties of null (reading 'toLocaleString')` 원천 차단.
2. **카드 및 모달 렌더링 널 가드**:
   - 후기 수: `hotel.reviewsCount != null && hotel.reviewsCount > 0`인 경우에만 `(후기 N건)` 노출, 미확인 시 태그 자체를 렌더링하지 않음.
   - 평점: `hotel.rating != null` 가드 적용.
   - 구글맵 후기 수: 이전 자리표시자 `(50)`을 전면 제거하고, 미확인은 `null`로 지정하여 배지 숨김.
   - 케이블카 거리: `hotel.cable_m != null`일 때만 `🚡 케이블카 역 Nm` 노출, 미확인 시 박스 완전 숨김 (`nullm` 노출 원천 방지).
   - 편의시설: `hotel.coreFacilities && hotel.coreFacilities.length > 0` 방어 적용.
   - 정렬 로직: `(a.cable_m ?? 99999) - (b.cable_m ?? 99999)` 및 `(b.reviewsCount ?? 0) - (a.reviewsCount ?? 0)`으로 null 안전 정렬 구현.
3. **사진 로컬 스토리지 영구 보관**:
   - 아고다 CDN 외부 핫링크 대신 `public/images/hotels/<slug>/photo_01.jpg` ~ `photo_06.jpg`로 전수 다운로드 저장.
   - 디렉터리/레지스트리 호환을 위해 `public/covers-photo/<slug>-1.webp` 생성.
   - 카드 상단 "사진 출처: Agoda ↗" 링크는 100% 정상 유지.
