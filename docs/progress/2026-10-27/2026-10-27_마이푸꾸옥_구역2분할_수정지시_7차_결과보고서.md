## 4. GoogleReviewAnalysisCard 및 lib/menus.ts 화면 비노출 검증 상세

지시 6번에 따라 `GoogleReviewAnalysisCard.tsx` (31·35행)와 `lib/menus.ts` (52·59행)의 화면 렌더링 경로를 전수 추적 조사한 결과입니다.

### 4.1 `GoogleReviewAnalysisCard.tsx` 비노출 검증 결과: **【화면 비노출 확인】**
1. **렌더링 경로**: `lib/routes/BusinessRoute.tsx:508-515`
   ```tsx
   {reviewAnalysis && (
     <GoogleReviewAnalysisCard
       analysis={reviewAnalysis}
       ...
     />
   )}
   ```
2. **비노출 원인**: `reviewAnalysis`는 `lib/googleReviewAnalyzer.ts:22`의 `analyzeGoogleReviews(b, locale)` 함수를 통해 생성되는데, 내부 코드(27~30행)에 다음 하드코딩 비활성화 플래그가 적용되어 있습니다:
   ```ts
   // [업무 지시 · Claude/Ryan] 구글 리뷰 실시간/실측 데이터 연동 전까지 모든 카테고리 렌더링 비활성화
   const DISABLE_PSEUDO_REVIEW_ANALYSIS = true
   if (DISABLE_PSEUDO_REVIEW_ANALYSIS) {
     return null
   }
   ```
   따라서 `reviewAnalysis`는 **어떤 조건에서도 항상 `null`을 반환**하며, 컴포넌트가 실제 화면 DOM에 일체 마운트되지 않습니다.
3. **조치**: 지시 원칙에 따라 문구를 수정하지 않고 **"비노출"**로 보고합니다.

### 4.2 `lib/menus.ts` GRADE_INFO (52·59행) 비노출 검증 결과: **【화면 비노출 확인】**
1. **정의 위치**: `lib/menus.ts:52, 59`
   - Line 52: `labelEn: 'Grade A · Full Menu Verified'`
   - Line 59: `labelEn: 'Grade B · Core Menu Verified'`
2. **참조 및 렌더링 경로 추적**:
   - `BusinessMenuSection.tsx:190-192`에서 `const gradeLabel = ...`, `const gradeDesc = ...` 변수로 선언만 되어 있을 뿐, **JSX 렌더링 블록 내부에서 일체 사용되지 않는 Dead Code** 상태입니다.
   - 실제 코드 주석(205행): `/* 메뉴 출처 및 기준일 메타 정보 표기 (여행자 친화적 표기, 내부 관리 등급 문구 노출 금지) */`에 명시된 바와 같이, 방문자에게 혼란을 주는 내부 관리용 등급 텍스트(`Grade A/B/C/D ... Verified`)의 노출을 원천 차단하고 있습니다.
   - 또한 `loadMenuForPlace()`가 반환하는 `menuData.gradeLabel` 역시 사이트 내 어떤 UI 컴포넌트에서도 호출되지 않습니다.
3. **조치**: 사용자 화면에 노출되지 않으므로 지시 원칙에 따라 문구를 수정하지 않고 **"비노출"**로 보고합니다.
