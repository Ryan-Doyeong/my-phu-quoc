# Claude 지시 — git push 승인 (Ryan 승인 2026-10-26 16:57)
대상: 지도 상단 점령 수정 + 지도 디자인 정리 + 히어로 손글씨 문구 제거 + 모바일 버튼 수정.

1. push 전 점검(결과를 보고에 포함):
   - git status (미커밋 변경 목록), git log origin/main..HEAD --oneline (올라갈 커밋 목록)
   - 올라갈 커밋이 위 4개 작업 범위(지도·히어로·모바일 버튼)뿐인지 확인. 다른 작업(예: 콘텐츠 정확도 v3 SQL, registry 변경, 마이그레이션, proxy.ts 등)이 섞여 있으면 push 하지 말고 목록만 보고.
2. 범위가 맞으면 git push origin main 실행. Supabase 마이그레이션·DB 변경은 절대 실행하지 말 것.
3. push 후 보고: push 결과(커밋 해시), 호스팅(Hostinger/Vercel 등)이 자동 배포되는지 여부와 배포 상태, 배포 완료 예상 시각. 자동 배포가 아니면 필요한 수동 절차만 안내(실행하지 말고).
4. 환경변수·키·비밀번호는 출력/기록 금지.
