## 목표
지도 섹션(#map)의 버튼·지도 표현·장소 설명을 깔끔하게 다듬되, 기존 사이트 디자인을 해치지 않는다.

## 기존 디자인 기준 (app/globals.css 에서 가져다 쓸 것, 새 색·폰트 도입 금지)
- 색: --ocean #0B7A8A, --ocean-deep #0A4F5C, --ocean-soft #DDF0EF, --amber #C86D2D, --amber-soft #FBEBDD, --paper #FCFEFD, --ink #12333B, --muted #5B7479, --line #D5E5E4
- 카드: 흰 종이 배경 + 1px --line 테두리 + radius var(--radius) + var(--shadow) (.businessCard / .storyCard 와 같은 결)
- 버튼: .primaryButton(바다색 알약형), .outlineDark(테두리 알약형) 재사용. 새 버튼 스타일 만들지 말 것.
- 섹션 제목: .eyebrow(작은 대문자 라벨) + .sectionIntro h2 스타일, 폰트 Pretendard(var(--font-pretendard)), 다른 섹션과 크기 일관.
- 다크 슬레이트 박스(bg-slate-900 등)·네온 느낌 금지 → 밝은 종이톤 카드로.

## 정리할 항목
1. 지도 표현: 일러스트 지도는 밝은 카드 안에 비율 유지(잘리지 않게 object-fit: contain), 모서리·그림자는 기존 카드와 동일. 클릭하면 라이트박스 확대(ESC·바깥 클릭·닫기 버튼). 지도 위 번호 1~12와 아래 목록 번호가 시각적으로 대응(번호 배지는 바다색 원형).
2. 버튼: 지도 아래 버튼 2개로 정리 — 「크게 보기」(outlineDark), 「고화질 다운로드」(primaryButton). 장소 카드 안에는 「구글맵 길찾기」 1개만(primary 작은 크기). 「할인 티켓 예매」는 해당 장소(티켓 있는 곳)에만 outline으로.
3. 카테고리 필터: 알약형 칩(선택 시 바다색 채움, 비선택은 outline), 모바일에서는 가로 스크롤. 이모지 과다 사용 금지.
4. 장소 설명 카드(12개): 한 카드 = 번호 배지 + 이름(한글 크게/영문 작게) + 한 줄 요약 + 추천 시간·도보 거리 두 칸 + 여행자 팁(연한 amber-soft 박스) + 길찾기 버튼. 긴 설명은 2~3줄만 보이고 「더 보기」로 펼침. 데스크톱 2열 / 모바일 1열.
5. 텍스트: 6개 언어 모두 줄바꿈·넘침 확인(ru·hi는 길어짐). 번역 판단은 하지 말고 기존 문구 그대로 사용(번역 감수는 ChatGPT 담당).
6. 섹션 제목·설명도 홈 다른 섹션과 같은 톤으로(영문 라벨 SUNSET TOWN ILLUSTRATED GUIDE MAP 은 .eyebrow 스타일로).
