# Claude 수정 지시 4차 (2026-10-25) — 언어 변경 + 사진 정리
규칙: 기존 파일 삭제·덮어쓰기 금지(새 파일/_v5, 기존 코드는 .orig 백업). Supabase 반영은 계속 대기. 비밀번호·로그인 직접 입력 금지. 확인 안 된 것은 "미확인". 사진은 자르기·크기조정만(합성·새 사물 추가 금지). 완료 후 짧게 보고.

## A. 지원 언어 변경 (Ryan 결정)
- 지원 언어는 6개: 한국어(ko), 영어(en), 중국어 간체(zh), 러시아어(ru), 일본어(ja), 힌디어(hi). 베트남어(vi)는 언어 선택·라우팅·sitemap·hreflang에서 제외(코드·사전 파일은 지우지 말고 비활성화만, 나중에 복구 가능하게).
- 기본 언어는 영어(en) 유지(해당 언어가 없을 때 대체).
- 언어 자동 선택: 처음 방문 시 브라우저 선호 언어(Accept-Language)를 읽어 6개 중 맞는 언어로 자동 표시(zh-CN/zh-TW/zh-HK는 zh로, 그 밖의 언어는 en). 사용자가 직접 고른 언어는 쿠키(예: NEXT_LOCALE, 1년)로 기억해 자동 선택보다 우선. 검색엔진 봇에는 URL의 언어를 그대로 보여주고 hreflang 유지(자동 이동은 첫 방문의 루트 경로에서만).
- 언어 선택 UI: 지금의 EN/VI/HI/中文/RU/KO/JA 작은 칩 대신, 헤더에 눈에 띄는 언어 선택 버튼(지구본 아이콘 + 현재 언어의 자국어 이름, 예: 한국어) → 누르면 6개 언어가 자국어 이름으로 보이는 드롭다운(한국어 / English / 中文 / Русский / 日本語 / हिन्दी). 현재 언어에 체크 표시. 모바일 메뉴에서도 같은 선택기가 맨 위에 보이게. 언어를 바꿔도 현재 페이지(같은 업체·같은 필터)에 머무를 것.
- 변경 후 6개 언어에서 홈·디렉토리·업체 상세가 깨지지 않는지 점검(번역 품질 검수는 하지 말고 비어 있거나 영어로 남은 문구 목록만 docs/translation_needed_terms_v2.md에).
- 필터 칩 등에 남은 영어 원문(예: "Russian")도 6개 언어로 표시되게.

## B. 사진 정리 (Claude 추천안, Ryan 승인)
1. data/cover-photos.json의 36곳 전수 점검: source_page_url의 도메인이 해당 업체의 공식 사이트(업체 website_url 또는 업체 공식 SNS)와 일치하는 것만 유지. 일치하지 않거나 확인 불가한 것은 모두 레터링으로 되돌림(JSON에서 삭제 대신 status:"revoked" + reason 기록).
   - 이미 확인된 오매칭: sunset-place-1(수산시장 사이트), sunset-place-5(약국 체인 배너), atm-sacombank·atm-kienlongbank-an-thoi(은행 홍보 배너), phu-quoc-go(투어 업체 일반 이미지) → 되돌릴 것. 유사한 일반 이름(sunset-place-*) 전부 재확인.
   - skyethgroup.com 출처 4곳(베니스 카페·베니스 호텔·로마 호텔·사쿠라쿄): 해당 업체의 모회사/공식 그룹 사이트가 맞는지, 업체 자체 공식 사이트(venicehotelphuquoc.com 등)에 같은 사진이 있는지 확인. 확인 안 되면 레터링으로, 확인되면 업체 자체 사이트의 사진으로 교체.
2. 금지 대상 재확인: 로고·배너·광고·메뉴판·지도·텍스트가 많은 이미지, 사람 얼굴이 크게 나온 사진, 워터마크 있는 사진은 쓰지 말고 레터링으로.
3. 사진을 쓰는 업체 중 가로세로 비율이 맞지 않아 어색하게 잘리는 것은 object-position 조정 또는 레터링으로.
4. 디렉토리 상단 배너(카테고리별 헤더)에 쓰인 사람이 크게 나온 스톡풍 사진을 교체: 사람이 없는 장면 또는 사이트 브랜드색(Ocean/Amber) 단색 배경 + 카테고리 이름 레터링으로. (새 사물 그려 넣기 금지, 기존 public/stock 안의 사람 없는 사진이 있으면 그것 사용)
5. "스톡 사진 0건" 보고가 정확했는지 다시 계산(public/stock 사용처 전체 목록을 보고서에 포함).
6. 사진 사용 업체 상세 하단에 "사진 삭제·수정 요청" 링크(업체 관리 권한 신청 페이지로)를 출처 표기 옆에 추가.
7. 사진 수집을 선셋타운 291곳 전체로 확대하는 것은 이번에는 하지 말 것(정확도 확보 후 별도 지시).
