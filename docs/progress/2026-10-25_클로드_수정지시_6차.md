# Claude 수정 지시 6차 (2026-10-25) — 히어로 확정 + WebP 상시 규칙 + 5차 미적용분 재적용
규칙: 기존 파일 삭제·덮어쓰기 금지(새 파일/_v7, 기존 코드는 .orig 백업). Supabase 반영은 계속 대기. 비밀번호·로그인 직접 입력 금지. 확인 안 된 것은 "미확인". 사진은 자르기·크기조정·포맷 변환만(합성·새 사물·이모지·아이콘 추가 금지). 완료 후 짧게 보고.

## A. 상시 규칙 (Ryan 지시, 앞으로 계속 적용)
사이트에 올리는 모든 이미지는 반드시 WebP로 변환해서 사용한다(업체 사진, 히어로, 배너, 커버 등 전부).
- 변환: 원본(jpg/png 등)은 건드리지 말고 새 .webp 파일을 만든다. 품질 약 80~85. 용도별 가로 크기 3종(예: 640 / 1280 / 1920px)을 만들어 srcset 또는 next/image로 제공.
- 코드에서 쓰는 이미지 경로는 .webp만. 기존 .jpg/.png 참조(public/covers-photo/, public/stock 등)도 .webp 사본으로 바꿔 참조(원본 파일은 삭제하지 말고 그대로 둠).
- 변환 스크립트를 scripts/convert_to_webp.mjs(또는 .py)로 만들어 앞으로 새 이미지를 넣을 때마다 쓸 수 있게 하고, 사용법을 docs/IMAGE_RULES.md(새 파일)에 3줄로 정리. 원본이 25MB급이므로 변환 후 파일당 대략 300KB 이하(히어로 1920px 기준 500KB 이하)를 목표.
- 보고에 변환 전·후 용량을 표로 포함.

## B. 홈 히어로: 2번 사진 확정 (Ryan 선택)
- 사진: docs/progress/2026-10-25/hero-candidates_v6/02_kiss_bridge_aerial.jpg (키스브릿지·선셋타운 항공 야경).
- 위 규칙대로 WebP 3종으로 변환(public/hero/ 새 폴더)해 홈 히어로로 적용. 사람 없는 장면이라 글자 가독성을 위해 어두운 그라데이션 오버레이는 허용(사진 자체를 바꾸지 말 것). 현재 히어로의 푸꾸옥이 아닌 강변 거리 사진(스톡)은 홈에서 완전히 제거.
- 라이선스 검증(필수): data/hero-photos.json의 02번 항목에 적힌 Wikimedia Commons 파일(File:Kiss_Bridge_Phu_Quoc_aerial_sunset_view.jpg)과 URL이 실제로 존재하는지 Chrome으로 Commons 페이지를 직접 열어 확인하고, 실제 작성자 이름·라이선스 이름과 버전·원본 페이지 URL을 정확히 기록. 페이지가 없거나 라이선스가 확인되지 않으면 "license_status: unverified"로 기록하고, 이 사진을 정식 공개(배포) 전 차단 항목으로 docs/PRELAUNCH_CHECKLIST.md(새 파일)에 올릴 것. 로컬 확인용 적용은 가능. 다른 후보(01, 04, 07 등)도 같은 방식으로 라이선스를 확인해 결과표를 보고(확인된 것만 다른 구역에 쓸 수 있음).
- 화면 하단에 작은 글씨로 사진 출처(작성자·라이선스·링크) 표기.
- 홈 히어로의 "매일 밤 21:00 불꽃놀이" 문구: 선그룹 선셋타운 공식 안내에서 시간을 확인하고 출처 URL 기록. 확인 못 하면 시간 삭제.

## C. 5차에서 화면에 반영되지 않은 항목 재적용
1. 타이포그래피: docs/design/myrealtrip-style-notes.md의 토큰을 실제 화면에 적용(스크린샷에서 업체 상세 제목, 홈 히어로 제목, 섹션 제목이 아직 큰 세리프체 그대로였다). 한국어는 Pretendard(OFL) 등 지정 폰트, 제목 크기는 노트의 스케일(예: 상세 제목 26px대, 히어로 40px/모바일 32px)을 따를 것. 업체 상세 제목은 한글명(큰 글씨)/영어명(작은 글씨)으로 분리.
2. 러시아어(키릴)·중국어·일본어·힌디어 폰트 스택이 실제로 해당 글자를 표시하는지 각 언어 화면에서 확인(분석표의 "Pretendard 키릴 글리프 내장" 부분은 확인 필요 → 실제 지원 여부를 조사해 사실대로 정정). 지원 안 되면 Noto Sans 등으로 대체.
3. 홈 중간 "Sponsored with Purpose" 구역 숨김(비활성화), 모바일 언어 드롭다운 잘림 수정이 반영됐는지 재확인.
4. data/hero-photos.json의 active_hero_in_production 값과 실제 화면이 일치하는지 확인(5차 보고와 스크린샷이 서로 달랐음).
