## 2. 카카오톡 / 오픈채팅방 공유용 요약본 (텍스트 복사용)

```text
[푸꾸옥 남부 선셋타운 & 썬월드 티켓 할인 총정리]

1. 키스 오브 더 씨 쇼 (불꽃놀이 분수쇼)

* 팁: 쇼 티켓 구매 시 키스 브릿지 입장 혜택 포함 옵션인지 꼭 확인하세요!

2. 썬월드 혼똔섬 케이블카 & 아쿠아토피아 워터파크

- 런치 뷔페 포함권: 약 5.0만 ~ 6.0만원

- Klook 할인가: 약 6.5만 ~ 7.8만원선
* 하루 동안 남부를 정복할 때 가장 가성비 좋은 추천 패키지입니다.

4. 북부(빈원더스/사파리)도 같이 가실 분:

```
