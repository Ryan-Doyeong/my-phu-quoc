# Hostinger deployment — v8.4

1. Upload the ZIP as a Node.js / Next.js Web App.
2. Framework preset: Next.js.
3. Node.js: 22.x.
4. Build/output: use Hostinger's Next.js defaults.
5. No environment variables are required for the core website.
6. Deploy.

The Supabase project URL and public publishable key are bundled in the app. The publishable key is intentionally public and access is controlled by Supabase RLS policies.
